# Echo Chamber 🔊

A horror / audio-visual survival game built for **CTRL+PLAY 2026 (Gamathon)** by The Gamers Crib.

You're trapped in a dark, abandoned laboratory. A **sonar pulse** reveals your surroundings — but every pulse makes sound, and **something is hunting** in the dark. Find all **3 keycards**, reach the exit, don't get taken.

## Play

Open `echo-chamber.html` in any browser — no internet needed, no install. Double-click and play.

**Controls:** WASD/arrows move · Shift = quiet move · Space = sonar pulse · Q/click = throw distraction · E = drop radio · R = restart · M = mute
