ECHO CHAMBER
Horror / audio-visual survival — CTRL+PLAY 2026 Gamathon entry
Single-file game. No install, no internet required.

LAUNCH
  Open echo-chamber.html in any modern browser (Chrome / Edge / Firefox).
  Double-click the file — it runs from file:// with the device offline.
  Keyboard required. Click once if the browser asks (enables audio).

OBJECTIVE
  You are trapped in a pitch-black abandoned laboratory.
  Find all 3 KEYCARDS, then reach the EXIT.
  A creature hunts by sound in the dark. Do not let it touch you.

CONTROLS
  WASD / Arrow keys .... move
  Hold SHIFT ........... move quietly (slower, nearly silent)
  SPACE ................ sonar pulse — reveals surroundings for ~2.5s
                         BUT the pulse is loud: the creature will hear it
  Q or click a tile .... throw a distraction (lures the creature away)
  F .................... throw 4 tiles in facing direction
  E .................... drop a radio (persistent lure, 12 seconds)
  R .................... instant restart (keeps collected keycards)
  M .................... mute
  ENTER ................ start / advance screens
  ESC .................. pause

RULES OF THUMB
  - Every pulse is a gamble: it shows you the lab, and shows the
    creature where you are.
  - Stand still for 1.5+ seconds to hide — it hunts by sound.
  - Sprint when it is far, go quiet in the mid-range, throw junk
    to pull it off your trail.
  - The exit unlocks (turns green) only with 3/3 keycards.

WIN / LOSE
  Step onto the green exit with 3 keycards ..... ESCAPED
  The creature gets within arm's reach ......... TAKEN (press R)

Contains flashing light effects (smooth sonar rings; no strobing).
